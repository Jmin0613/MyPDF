# 🐣 MyPDF 🐣

개인적으로 사용하기 위해 만든 간단한 데스크톱 PDF 유틸리티입니다.

PDF 파일을 외부 서버에 업로드하지 않고 로컬 PC에서 처리합니다.

## 📢 기능

### PDF 병합

여러 PDF 파일을 원하는 순서로 정렬하여 하나의 PDF로 병합합니다.

### PDF 분할

`1-5, 8, 10-15`와 같이 페이지를 지정하여 원하는 페이지만 새로운 PDF로 저장합니다.

### PDF 정리

PDF 페이지를 썸네일로 확인하면서 정리할 수 있습니다.

- 드래그 앤 드롭으로 페이지 순서 변경
- 필요한 페이지만 선택하여 저장
- 불필요한 페이지 삭제
- 원본 상태로 초기화

## 📢 실행 방법

### 요구 환경

- Java 25
- Windows

### 실행

저장소를 Clone합니다.

```bash
git clone https://github.com/Jmin0613/MyPDF.git
cd MyPDF
```

또는 GitHub에서 ZIP 파일을 다운로드한 뒤 압축을 해제합니다.

PowerShell 또는 터미널에서 다음 명령어를 실행합니다.

```powershell
.\gradlew.bat run
```

최초 실행 시 필요한 Gradle 의존성을 다운로드하기 위해 인터넷 연결이 필요할 수 있습니다.

PDF 병합, 분할 및 정리 작업 자체는 외부 서버를 사용하지 않고 로컬에서 처리됩니다.
